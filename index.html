What is Redrose?

Redrose Linux is a modern Linux distribution focused on simplicity without dumbing things down.

The core aims are to be FOSS-only and dev-friendly. We are based in Slovakia, and are the second ever distro from Slovakia. Note that the distro before us is discontinued.

You might also remember us as "Minixor Linux" and "Crust Project". The name was changed to Redrose Linux in October-November 2025.

✔ Based in the EU ✔ x86_64 only ✔ Custom installer ✔ NixOS-like features ✔ Riced, but still simple ✔ Custom desktop enviroment ✔ Custom package manager ✔ Independent (Arch-based for beta)

This project was my dream ever since I was 8 years old, and what finally made me start doing it was a Linux shell. I started building a Linux distro around it, and this is the result.
