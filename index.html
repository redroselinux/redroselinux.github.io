Redrose Linux

An independent x86_64 systemd-free FOSS-only-by-default Linux distribution from Slovakia. We have a custom package manager and a custom DE is coming soon. There are also plans for reproducibiity in the distro.

Download (alpha) GitHub Docs

Why?

The main issue with a lot of distros is:

  1. They are reskins of Debian or Arch
  2. They have a cool feature that is implemented in a bad way
  3. I had to say it. Their package managers are slow.
Redrose Linux implements features from distros as Arch, NixOS and others into one distro.

The installer is made in C.

Our package manager - Car

Car fixes a big issue of a lot of classic package managers as APT or DNF, which is speed. Car is extremely fast and uses a .tar.zst format, however it supports native conversion of .deb files (support for other formats is coming soon!).

Car is made in Nim.
