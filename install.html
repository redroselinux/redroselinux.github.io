Redrose Linux Docs GitHub Waitlist

The Redrose Linux beta is Arch-based. Later, we will have an installer and will be fully independent, but for now, run: archinstall Install Arch using your preferences and after it is done, say Yes to the prompt about using chroot.
Then, you want to install car: curl -s -L -o /usr/bin/car https://github.com/redroselinux/car/releases/download/20/car chmod +x /usr/bin/car You now have a minimal install of Redrose Linux. Other tools are not yet finished, so until we make an installer for the Arch beta, this is your sneak peek at how will Redrose work! Remember, later we will be independent.
