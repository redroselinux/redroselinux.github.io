i4 Desktop Environment

i4 is the custom desktop environment included with Redrose Linux. It is built directly on top of the i3 window manager, retaining its lightweight tiling workflow while adding new tools, integrations, and visual improvements.

This page documents the base i3 behavior as well as i4-specific functionality.

Installation

i4 is preinstalled on Redrose Linux. No setup is required - simply log in to the i4 session from your display manager or TTY.

Installation instructions for other Linux distributions will be added soon.

Dependencies

i4 relies on the following software components:

  • i3 - base window manager
  • picom - compositor for transparency and animations
  • rofi - app menu
  • polybar - status bar
  • scrot - screenshot backend
  • xprintidle - idle detection for the lock screen

Redrose Linux ships all of these by default. External distros may need to install them manually.

Configuration

i4's i3 configuration is located at:

directory~/.config/i3/config

You can use standard i3 configuration syntax. i4 adds extra sections (documented below) that you can also customize.

Keybindings

i4 inherits all standard i3 keybindings unless overridden. Defaults:

Window focus

$mod+h   Focus left
$mod+j   Focus down
$mod+k   Focus up
$mod+l   Focus right

Window management

$mod+f           Toggle fullscreen
$mod+Shift+space Toggle floating mode
$mod+v           Split vertically
$mod+h           Split horizontally

Launching applications

$mod+Return  Open terminal
$mod+d       App launcher (rofi or dmenu depending on i4 settings)

Workspaces

i4 uses standard i3 workspace behavior.

$mod+1 -> Switch to workspace 1
$mod+Shift+1 -> Move focused window to workspace 1

i4 Features

i4 extends i3 with additional user-oriented tools.

i4 Lock Screen

i4 includes its own lockscreen, however it uses i3lock as the backend. Idle detection uses xprintidle. Configuration documentation coming soon.

i4 Settings App

The i4 settings application is currently in development. It will allow users to configure:

  • Themes
  • Keybindings
  • i4 modules
  • Compositor settings
  • And more system basics

i4 Screenshot Tool

i4 will include a built-in screenshot tool that uses scrot as the backend. GUI mode and editing tools are still in development.

Status Bar (polybar integration)

i4 uses polybar for its default status bar, preconfigured with:

  • Workspace indicators
  • CPU and RAM info
  • Clock

Compositor (picom)

i4 ships with a tuned picom configuration for:

  • Fading animations
  • Transparency effects
We made our compositor configuration very friendly even for graphic designers, so your black color won't turn gray.
