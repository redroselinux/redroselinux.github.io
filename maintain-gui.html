Usage

First, clone the repo: git clone https://github.com/redroselinux/maintain cd maintain Now run the install script:* chmod +x ./install.sh ./install.sh If you want desktop shortcuts, answer Y to this: Make desktop shortcuts for the commands? [y/N] The script requires sudo* Now run: redrose-maintain You will see a simple UI. This UI fetches the latest packages and lets you rebuild them if you want to.
